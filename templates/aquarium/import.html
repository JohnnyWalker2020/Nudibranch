What the file should look like

Any file from Export works. For your own, a first row of headings and either layout:

Date,Parameter,Value,Unit
2026-03-25 09:00,Alkalinity,8.4,dKH
2026-03-25 09:00,Calcium,430,ppm
Date,Alkalinity (dKH),Calcium (ppm),Nitrate
2026-03-25 09:00,8.4,430,5

Tests are matched by name (or short names like Alk, Ca, Mg, NO3, PO4). Values in another unit are converted when the app knows how, such as SG to ppt or °C to °F. A reading already logged for the same test, tank and minute is skipped, so importing a file twice is harmless.
