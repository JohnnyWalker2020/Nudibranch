Using webhooks with equipment

  • Keep your feeder's own schedule as the main one. If this PC or Docker is off, no webhook is sent.
  • Point hardware at one routine. Edit the connection and tick only that routine, so it can't fire for your lights or a parameter alert.
  • Each automated schedule event is sent once. A missed one is dropped after 5 minutes and never retried, so it can't feed twice by accident.
  • Every event has a unique id, so the device receiving it can ignore repeats. Give anything that doses or feeds its own daily limit.
  • For Home Assistant, use http://YOUR-HA-IP:8123/api/webhook/YOUR-ID. Names like homeassistant.local may not work from inside Docker.
  • Add a secret and JSON webhooks are signed with HMAC-SHA256 in X-Nudibranch-Signature.
